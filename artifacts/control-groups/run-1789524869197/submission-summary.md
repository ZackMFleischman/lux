LUX-97 adds optional named groups to numeric control declarations and renders them as nested disclosures inside Controls. SDK 0.2 scenes and SDK 0.4 component/exposure aliases preserve group metadata and declared order. Ungrouped controls retain the existing row UI. The shipped authoring skill and noise-sphere example describe meaningful grouping while keeping small sets simple.
