## Implementation approach

Use existing shader-field transport and a minimal explicit Ornament producer/consumer agreement established by one working shape-and-color demonstration. Preserve the existing exact-key v1 painting contracts. Declare the new contract and compatibility strategy before dispatching parallel module edits. Do not add a general shader linker or generic geometry framework. Field nodes can share one assembled paint shader rather than each creating a render pass.

Parallel lanes after interface agreement: geometry; boundary/ribbon; packed motifs; structural line motifs; composition/color. Each lane owns separate files. GPU tests, shared Library writes and main integration are serialized with the existing Lux delivery task. Independent review happens once per integrated batch, with targeted re-review only for changed findings.

## Artistic acceptance

For each visual batch capture three deterministic seeds, a full composition and a detail view, plus separated animation checkpoints when motion changes. Record source/controls/time/seed with actual Lux captures. Inspect the following and iterate material defects before publication:

- Large, medium and small forms read as a hierarchy; no uniform cellular wallpaper.
- Broad lobes, deep bays, narrow corridors and localized complex contours remain distinct.
- Shared edges meet cleanly; nested regions have intentional negative space.
- Quiet pale areas balance dense motifs; neighboring families contrast coherently.
- Mark variation stays recognizable: spiral packing, circle gaps, unequal membrane fans, and readable stripes.
- Black and colored outlines vary deliberately without excessive visual weight or accidental seams.
- Yellow/warm anchors and pink/blue/purple relationships unify distant areas.
- Motion preserves identities and attached patterns; no random reseeding, accidental sliding or synchronized global pulse.
- Topology events have readable preparation, change and settling; daughter styles transition smoothly.

A successful compile or numerical match alone is not artistic acceptance. Existing painting regression uses exact timed comparisons where the source should remain unchanged. New art uses visual judgment against these principles, not pixel matching to the reference photograph.
